# Public video link support

ClippingAI includes yt-dlp-based fetching for supported publicly accessible YouTube, Facebook and Instagram URLs. It does not bypass DRM, log in to private accounts, evade paywalls, or defeat access controls.

Platform websites change frequently. Some videos may require login, be private, age/region restricted, blocked by rate limits, or unavailable to the downloader. Such links will fail and the project will show a failure status.

Use the file upload option when a link cannot be fetched. The source must be a video you are entitled to process.
