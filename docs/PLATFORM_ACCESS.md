# Platform access and rights

## Safe supported path in this MVP
Upload a source file that you own, have licensed, or are otherwise legally authorized to process. The app stores the source on your API server and processes that local copy.

## External URLs
The URL endpoint validates and records supported YouTube, Facebook and Instagram links. It does not download media. A URL alone is not proof of permission to download or process the underlying video.

## Official integrations
A future integration must use the relevant official API and follow its current developer terms, OAuth scopes, app review, account eligibility, content ownership and rate limits. Do not ask users for platform passwords. Do not scrape private endpoints, evade rate limits, bypass DRM or circumvent login/access controls.

- YouTube: API access is not a general license to download arbitrary videos. Use creator-authorized uploads or a specific permitted API workflow.
- Facebook / Instagram: access depends on Meta app review, supported account types, permissions and the user's relationship to the content. Live access has additional limitations.

## Copyright
Cropping, subtitles, zooms, music or transitions do not automatically make a use lawful. Fair use / fair dealing is fact- and jurisdiction-specific. Keep source provenance and rights records, review each clip, and use properly licensed music and sound effects.
